How it works

Six steps, from raw text to a decision. Steps 1–3 run on this computer with no AI at all; steps 4 and 6 each make one call to the language model.

  1. Split the message into words

    Contractions are opened up so each part gets its own language.

    Ako'y becomes Ako + 'y (ay); 'cause means because.

  2. Tag each word

    A slang list, word lists of about 4,800 Tagalog and 49,000 English words, and an optional Tagalog dictionary decide most words. For affixed words, the root decides, including Taglish verbs like nagsho-shopping.

    nagutom has the Tagalog root gutom; nag-wait has the English root wait.

  3. Measure the mix

    Density is the share of the less-used language. 0 means one language only; 0.5 means a perfectly even mix.

    Single-language: 0. Low mix: up to 0.3. High mix: above 0.3.

  4. Ask the model once

    One call returns the intent, how confident the model is, and the language of any word the word lists didn't know, such as slang.

    jowa isn't in the lists, so the model tags it.

  5. Answer or hand off

    If the model's confidence is below the threshold you set, the message goes to a person instead of being answered automatically.

    The default comes from a rule fixed before testing: answered messages must be at least 95% correct.

  6. Translate automatically

    Rewrite the whole message in plain English or plain Tagalog, keeping names and tone.

    Done automatically after each analysis, in both languages at once.
